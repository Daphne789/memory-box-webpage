# Service-Learning Project Webpage
This webpage presents the proposed **“My Story, My Choice” Memory Box Programme**, developed as part of a service-learning assignment with elderly participants at a senior centre.
The website serves as a visual annex to the written report, illustrating the core challenge identified, the programme concept, session structure, and implementation considerations. It is intended to support assessors’ understanding of the proposal and demonstrate how the proposed programme could be communicated in a simple, accessible format.
